# Supermart Grocery Sales Dashboard

## 📊 Data Analyst Internship – Task 4

This project was completed as part of **Task 4 – Dashboard Design** of my Data Analyst Internship.

The objective of this task was to create an **interactive business dashboard** using Microsoft Power BI.

## 🛠️ Tools Used

- Microsoft Power BI
- Supermart Grocery Sales Dataset

## 📁 Dataset

**Supermart Grocery Sales – Retail Analytics Dataset**

Important columns used:

- Order ID
- Customer
- Category
- Sub Category
- City
- Order Date
- Region
- Sales
- Discount
- Profit
- State

## 📈 Dashboard Features

### KPI Cards
- Total Sales
- Total Profit
- Total Orders
- Sales Growth

### Visualizations
- Sales Trend Over Time – Line Chart
- Sales by Category – Column Chart
- Sales by Region – Column Chart

### Interactive Filters
- Category Slicer
- Region Slicer

The slicers allow users to filter the dashboard and dynamically view the corresponding sales information.

## 🎯 Key Learning Outcomes

Through this task, I learned:

- Creating interactive dashboards in Power BI
- Creating and using KPI cards
- Creating sales trend visualizations
- Using slicers and filters
- Comparing sales across categories and regions
- Designing a clean and professional dashboard
- Presenting data for business decision-making
